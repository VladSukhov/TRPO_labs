# Документация проекта TRPO Labs

## Описание
Это учебный проект для демонстрации CI/CD процессов.

## API Reference
### math_ops.py
- `add(a, b)`: Возвращает сумму двух чисел.
- `multiply(a, b)`: Возвращает произведение двух чисел.
- `sub(a, b)`: Возвращает разность двух чисел.

*Документация автоматически обновляется при каждом push в ветку main.*
